# Caller

Интерфейс для iPhone на SwiftUI. Проект открывается в Xcode через `Caller.xcodeproj`. Минимальная версия системы в проекте — iOS 26.2.

Избранное, недавние звонки и контакты используют вымышленные данные для проверки интерфейса без доступа к личным данным. Изменения избранного хранятся до перезапуска приложения. Клавиатура передаёт набранный номер системному обработчику телефонных вызовов. Для международного номера удерживайте ноль, чтобы ввести плюс.
